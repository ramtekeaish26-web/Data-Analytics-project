# Student Performance Analysis 

This project analyzes student performance data using Python and Power BI.

The main aim is to understand student marks, attendance, study hours, branch-wise performance, semester-wise performance, and risk levels.

## Tools Used

- Python
- Pandas
- Matplotlib
- Power BI
- CSV / Excel

## Project Steps

1. Loaded the student dataset using Python.
2. Checked and cleaned the data.
3. Used Python and Pandas for basic analysis.
4. Created charts to understand the data.
5. Created an interactive dashboard in Power BI.
6. Prepared a report based on the findings.

## Dataset

The dataset contains **200 student records** with details such as:

- Student ID
- Gender
- Branch
- Semester
- Attendance
- Internal and External Marks
- Assignment Score
- Study Hours
- Previous Semester Marks
- Final Marks
- Grade
- Result
- Risk Level

## Key Results

- **Total Students:** 200
- **Average Final Marks:** 71.37
- **Average Attendance:** 81.52%
- **Average Study Hours:** 3.49 hours/day
- **Low Risk Students:** 156
- **Medium Risk Students:** 41
- **High Risk Students:** 3

## Dashboard

The Power BI dashboard shows student performance through cards, charts, and comparisons based on branch, semester, gender, attendance, and other factors.

Dashboard screenshots are available in the `04_PowerBI` folder.
